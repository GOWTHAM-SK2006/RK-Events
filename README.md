# RK Catering & Events Management – Premium Business Website

A luxury, high-performance static business website built for **RK Catering & Events Management**, located in Devanurpudur, Udumalpet, Tamil Nadu.

Designed with royal South Indian wedding banquet aesthetics, combining **Deep Maroon (`#4A1020`)**, **Warm Cream (`#FFF8EF`)**, and **Antique Gold (`#C9A45C`)** with elegant serif typography and rich food photography.

---

## 🌟 Features & Sections

1. **Navigation Bar**: Transparent over hero, solid glassmorphic on scroll, mobile drawer, instant call action, and "Get a Quote" CTA button.
2. **Hero Section**: Full-screen visual experience with ambient zoom, badge for Devanurpudur & Udumalpet, headings, and value proposition highlights.
3. **About Us**: Focuses on authentic regional Kongu & South Indian culinary heritage, pure ingredients, clean uniforms, and customer satisfaction (with zero invented history).
4. **Our Services**: 8 showcase categories (Wedding Catering, Birthday Party Catering, Engagement Catering, Corporate Events, Family Functions, Traditional South Indian Catering, Buffet Catering, Event Management).
5. **Signature Food Experience**: Interactive multi-category showcase with pure veg and non-veg badges, Kongu specialties, and customizable notes.
6. **Why Choose Us**: 6 key pillars (Quality Ingredients, Delicious Food Experience, Elegant Food Presentation, Professional Service, Memorable Celebrations, Attention to Detail).
7. **Event Experience Banner**: Full-width high-impact section with call-to-actions.
8. **Interactive Gallery**: Filterable grid featuring authentic local event photos (Devanurpudur hall wedding meals, peacock fruit carvings, watermelon artistic carvings, buffet banquet styling) with full Lightbox modal navigation.
9. **Testimonials**: Elegant feedback carousel with clear demonstration disclosures.
10. **FAQ Section**: Common questions covering booking lead times, capacities (up to 5,000+), service radius, and menu customization.
11. **Contact & Maps**: Comprehensive contact details, Google Maps embed placeholder for Devanurpudur/Udumalpet, interactive inquiry form with automatic WhatsApp quotation link generator.
12. **Quote Modal**: 3-step interactive event planner and quotation generator.
13. **Floating WhatsApp CTA**: Instant contact widget with notification badge.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Images**: Next.js Image optimization (`next/image`)

---

## 📁 Content Management

All business content, phone numbers, WhatsApp, address, services, menu items, gallery items, and testimonials are centralized in one single file:

```
src/data/cateringData.ts
```

Edit this file to update any phone number, email address, pricing, or menu item without modifying code.

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run local development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for production
```bash
npm run build
```

---

## 🌐 Deploying to Vercel

1. Push this repository to GitHub, GitLab, or Bitbucket.
2. Go to [Vercel](https://vercel.com) and import the repository.
3. Vercel automatically detects Next.js.
4. Click **Deploy**. Zero configuration needed!
